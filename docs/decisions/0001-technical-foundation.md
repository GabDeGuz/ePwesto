# ADR-0001: Initial development foundation

Status: Accepted
Date: 2026-09-23
Related EPW tasks: EPW-026, EPW-027, EPW-028, EPW-029

## Context

ePwesto requires a repeatable, compatible starting point for its approved
Laravel/Tailwind web/backend and React Native mobile applications. The project
owner explicitly authorized initialization in this task.

## Decision

- Use the Laravel 13 generated application baseline with PHP 8.3 or later.
- Use the generated Tailwind/Vite frontend baseline supplied by Laravel 13.
- Use React Native 0.87.1 generated by the official community CLI, with Node.js
  22.11 or later; Node 24.18.0 was used for local validation.
- Use npm lockfiles for JavaScript dependencies and Composer lockfiles for PHP.
- Keep MySQL as the approved production database. Do not start it, connect to
  it, create a production schema, or run ePwesto data migrations in this task.
- Laravel may host the web administration interface and future backend/API; its
  exact API contract and authentication approach remain TBD.

## Consequences

The baseline enables deterministic checks without authorizing product modules or
unresolved policies. A workspace-local PHP/Composer copy may be used when the
host lacks those tools; it is ignored in `.tools/` and is not a project runtime
or a committed dependency.

## Verification

The generated Laravel and React Native baselines passed their documented checks
in EPW-029. See [TESTING.md](../TESTING.md).
