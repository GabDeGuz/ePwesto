# EPW-028: React Native initialization

## Goal

Create the uncustomized React Native baseline in `apps/mobile/`. No ePwesto
screen, API integration, account flow, or product module is included.

## Dependencies

EPW-026 baseline decision and Node/npm.

## Validation

Type check, generated baseline tests, linting, public configuration inspection,
and dependency audit. Android/iOS builds remain deferred until supported SDK and
platform decisions are documented.
