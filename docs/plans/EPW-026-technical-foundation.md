# EPW-026: Technical foundation and decisions

## Goal

Record the minimum development-tooling and application-boundary decisions needed
to initialize empty Laravel and React Native workspaces. This task does not
approve authentication, permissions, API semantics, database schema, payments,
documents, notifications, or deployment.

## Scope

- Establish reviewed runtime/framework baselines compatible with local tooling.
- Add ePwesto-specific architecture, API, role/permission, and testing guidance.
- Record unresolved decisions in the existing register.

## Exclusions

No product module, migration, external integration, provider selection, or
authorization workflow is implemented.

## Acceptance and validation

- ADRs identify the exact baseline and its rationale.
- Documents preserve all human decision points and FCFS section scoping.
- Repository-hygiene validation passes.
