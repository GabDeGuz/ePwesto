# Code Hygiene

Implementers inspect task-created obsolete, duplicate, or abandoned code and
report it. Clearly task-created remnants may be removed within scope; ambiguous
or unrelated findings require a separate bounded task. Hygiene never justifies
weakening tests or deleting framework/dynamic references without investigation.

Lead and Reviewer also check that ownership moves do not leave duplicate routes,
components, APIs, dependencies, or stale contracts. Hygiene cannot broaden scope.
