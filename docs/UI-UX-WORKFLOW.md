# UI/UX Workflow and Design QA

Before UI work, link the approved EPW task, user journey, requirements, and any
reviewed Figma artifact. Record affected states, responsive/platform impact,
accessibility considerations, and explicit non-goals. Do not infer a design
system because no reviewed ePwesto design baseline exists.

Design QA checks the exact candidate for hierarchy, readable layout, semantic
controls, focus/touch behavior, loading/empty/error states, accessibility cues,
and applicable viewport/platform behavior. Record the QA result using the shared
evidence template and synthetic inspected artifacts only.
