# Local Verification Evidence

This directory is a local, Git-ignored holding area for inspected task evidence
such as screenshots, traces, and test reports. Only this policy and its ignore
file are tracked.

Use synthetic data only. Before sharing an artifact, inspect it for secrets,
private URLs, real applicant/vendor/payment/document data, and unrelated screen
content. Do not force-add evidence files. For documentation or repository-only
tasks, record why visual evidence is not applicable in the task handoff.
